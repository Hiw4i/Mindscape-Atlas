# Mindscape Atlas - Атлас психологии человека

Интерактивная энциклопедия психологии, человеческого поведения, отношений, мышления и жизни. Локальная база знаний, которую вы наполняете своим контентом: источники разбиваются на идеи, идеи связываются с темами, из них собираются статьи, мифы и карта связей.

Главный принцип: максимум смысла, минимум воды. Система хранит, структурирует и связывает знания; содержимое определяет редактор.

Английская документация: [README.md](README.md).

## Быстрый старт

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000. При первом запуске база создаётся автоматически (data/atlas.db) и наполняется демонстрационными материалами, помеченными значком Демо.

Админ-панель: http://localhost:3000/admin/login. Пароль задаётся в .env.local, переменная ADMIN_PASSWORD (по умолчанию atlas-admin - смените её).

## Сценарии команд

| Команда | Что делает |
| --- | --- |
| npm run dev | Запуск для разработки |
| npm run build / npm run start | Продакшен-сборка и запуск |
| npm run db:generate | Перегенерация SQL-миграций после изменения схемы |
| npm run db:seed | Ручное создание базы и засев демо-контента |

## Как устроена база знаний

- Темы и разделы - дерево без ограничения глубины. Верхний уровень - разделы (Любовь и отношения, Общение и люди и другие), внутри - темы-понятия.
- Статьи - гибкий набор смысловых блоков: главный вопрос, краткая суть, глубокий разбор, распространённые заблуждения, примеры, практические выводы. Пустые блоки не отображаются. Каждая статья несёт степень достоверности: подтверждено исследованиями, гипотеза, авторская интерпретация, личное наблюдение, смешанные данные, спорный вопрос.
- Мифы и заблуждения - разбор популярного утверждения с вердиктом: опровергнуто, вводит в заблуждение, частично верно, не подтверждено, спорно.
- Источники - видео, книги, лекции, исследования. Из источника выписываются отдельные идеи с цитатами и таймкодами.
- Идеи - атомарные мысли. Связываются с темами и между собой: развивает, дополняет, оспаривает.
- Состояния - вход в базу через переживание ("Мне страшно знакомиться", "Меня отвергли"), собирающий статьи, темы и мифы.
- Связи тем - типизированные связи между понятиями. Из них строится интерактивная карта (страница /map).
- Поиск - полнотекстовый (FTS5) по заголовкам, тексту, тегам и их синонимам, с префиксным сопоставлением и подсветкой совпадений.

## Рабочий процесс наполнения

1. Добавьте источники: видео по ссылке, книги, исследования.
2. Выпишите из каждого источника отдельные идеи и привяжите их к темам.
3. На основе идей пишите статьи в редакторе с блоками структуры.
4. Разбирайте популярные утверждения в разделе Мифы.
5. Связывайте темы между собой - карта связей строится автоматически.
6. Создавайте состояния и собирайте в них материалы по конкретным переживаниям.

## Резервная копия и перенос

Вся база - один файл data/atlas.db рядом с проектом (каталог исключён из git, потому что содержит личный контент). Для копирования достаточно скопировать файл. Репозиторий на GitHub - это резервная копия кода; копии самой базы храните отдельно (зашифрованное облако, внешний диск или отдельный приватный репозиторий со снапшотами).

## Перенос на хостинг

Схема рассчитана на SQLite через Drizzle ORM. Для внешнего окружения замените драйвер: Turso (libSQL совместим с SQLite) или Postgres через соответствующий драйвер Drizzle. Код приложения работает с базой через слой запросов src/lib/queries.ts.

## Структура проекта

```
src/
  app/               страницы сайта и админки (App Router)
    admin/actions/   серверные экшены редактора
  components/        интерфейсные компоненты, карта связей, рельс маршрута
  db/                схема Drizzle, миграции применяются при запуске,
                     FTS-индексы, демо-контент
  lib/               запросы к базе, поиск, авторизация, словари
docs/
  design/            дизайн-бриф ("психика - местность, чтение - маршрут")
drizzle/             SQL-миграции
data/                файл базы (в git не входит)
```

## Стек

Next.js 15 (App Router) + TypeScript + React 19, SQLite (better-sqlite3) + Drizzle ORM, FTS5 для поиска, Tailwind CSS 4, d3-force для карты связей, lucide-react для иконок. Шрифты Literata и IBM Plex Mono с кириллицей.

## Безопасность

- Админ-панель - закрытый раздел для одного редактора на локальной установке. Задайте ADMIN_PASSWORD и SESSION_SECRET в .env.local; если ADMIN_PASSWORD не задана, используется встроенный пароль по умолчанию с предупреждением в логе.
- Сайт является образовательным ресурсом. Он не ставит диагнозов и не заменяет психологическую и медицинскую помощь.
